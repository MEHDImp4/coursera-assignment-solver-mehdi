## Design Context

### Users
General Coursera students using a compact browser-extension popup while actively working through course material. Their main job is to configure an AI provider once, then solve or extract quiz content with minimal interruption.

### Brand Personality
Fast, clean, and confident. The interface should feel capable and direct without becoming technical, noisy, or overly playful.

### Aesthetic Direction
Preserve the existing light, crisp Outfit typography and blue-and-amber action hierarchy, with an equally considered dark theme. Prefer progressive disclosure over dense settings, concise labels over jargon, and compact controls that fit naturally within a 360px extension popup.

### Design Principles
- Keep the primary course actions immediately understandable to non-technical students.
- Hide provider complexity until configuration is needed, then make every choice explicit.
- Use color semantically: blue for AI actions, amber for course automation, green for confirmed state, and red only for errors.
- Preserve strong keyboard focus, readable contrast, reduced-motion behavior, and clear live status feedback.
- Never sacrifice trust: explain where keys are stored and never silently switch providers or create unexpected API usage.
